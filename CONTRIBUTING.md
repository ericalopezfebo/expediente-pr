# Contribuir

Gracias por contribuir a Expediente PR.

1. No incluyas datos reales, confidenciales o privilegiados en código, issues o pruebas.
2. Crea una rama y acompaña los cambios con pruebas.
3. Ejecuta `ruff check .` y `pytest -q` antes de abrir el pull request.
4. Las reglas jurídicas requieren fuente primaria, fecha de vigencia y revisión humana.
5. Una prueba aprobada no convierte un cálculo en asesoramiento jurídico.
