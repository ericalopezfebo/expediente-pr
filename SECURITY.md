# Política de seguridad

Expediente PR aún está en desarrollo temprano y **no debe utilizarse con información
confidencial de clientes**.

No publiques vulnerabilidades en un issue público. Utiliza el mecanismo privado
**Report a vulnerability** de GitHub cuando esté habilitado para el repositorio.

## Principios del proyecto

- Separación estricta de datos por bufete.
- Mínimo privilegio y permisos por función.
- Registro inmutable de operaciones sensibles.
- Ningún documento de cliente se usa para entrenamiento.
- Resultados jurídicos sujetos a revisión humana.
- Las fechas límite deben conservar autoridad, explicación y versión de la regla.

Consulta `docs/SECURITY-ARCHITECTURE.md` antes de implementar almacenamiento,
autenticación, integraciones o funciones de inteligencia artificial.
